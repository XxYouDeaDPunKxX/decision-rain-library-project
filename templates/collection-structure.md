# Collection Structure

Recommended Raindrop collection structure:

```text
Decision Rain Library Project
  00_SYSTEM
  00_INBOX
  10_REVIEW
  20_LIBRARY
  90_ARCHIVE
```

## Collection Roles

`00_SYSTEM` contains the governance documents.

`00_INBOX` contains new links before evaluation.

`10_REVIEW` contains entries worth analysis before becoming decisions.

`20_LIBRARY` contains evaluated and operator-validated decision entries.

`90_ARCHIVE` contains rejected, inactive, outdated, duplicated, or historical entries.

## Rule

Every new link starts in `00_INBOX`.
The assistant may preserve immediately, but final placement requires operator validation.
