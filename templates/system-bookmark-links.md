# SYSTEM Bookmark Link Templates

Raindrop requires each bookmark to have a URL.
For SYSTEM documents that live only inside Raindrop, use stable placeholder URLs.

Example:

```text
https://example.com/rdl-agent-contract
https://example.com/rdl-system-spec
https://example.com/rdl-tag-registry
https://example.com/rdl-decision-rules
https://example.com/rdl-note-template
https://example.com/rdl-examples-golden
https://example.com/rdl-usage-flow
```

The URL is not the source of truth.
The bookmark excerpt is the source of truth for SYSTEM content.

If the assistant can only open the placeholder URL and cannot read the Raindrop excerpt, it must stop and ask for access to the SYSTEM content.
